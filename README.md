# SeatSheet 桌面座位表

随时查看班级座位安排，并快速随机点名。适用于 Windows 10 / 11 x64，需要连接已有的 SeatSheet 网站。

[**下载桌面版**](https://github.com/AtriDayo/SeatSheet.Widget/releases/tag/widget-v0.1.0-beta.2) · [**下载 ClassIsland 插件（可选）**](https://github.com/AtriDayo/SeatSheet.Widget/releases/tag/plugin-v0.1.5)

| 下载什么 | 适合谁 | 文件 |
| --- | --- | --- |
| 桌面版 | 查看座位表、设置名单与权重、使用随机点名 | `SeatSheet.Widget.exe` |
| ClassIsland 插件 | 希望用 ClassIsland 原生提醒展示点名结果 | `SeatSheet.ClassIslandPlugin.cipx` |

**仅在本软件查看和点名，无需安装插件。** 两个产品独立发布和编号。目前提供的桌面版为 `0.1.0-beta.2`，插件为 `0.1.5`，均为预发布测试版。下载入口指向已发布版本；源码中正在准备的版本不代表已经提供下载。

## 安装与首次使用

1. 打开桌面版下载页，在 **Assets** 中下载 `SeatSheet.Widget.exe`，直接运行，无需另行安装 .NET。不要下载 `Source code`，它不是可运行程序。
2. 进入设置；若没有自动打开，在桌面右侧“座位”按钮上右键，选择“设置”。
3. 填写你所在班级的 SeatSheet 网站地址，点击“测试连接”。格式示例：`https://seats.example.com`，请替换为自己的地址。
4. 确认显示正确的班级名称，点击“保存设置”。
5. 点击右侧“座位”按钮查看座位表，可调整把手样式、面板宽度和缩放。

软件不包含网站服务端，也不会代替网站修改座位安排。“管理座位”会在浏览器中打开网站管理页面。

## 随机点名

在 **设置 → 随机点名** 中查看参与名单，调整权重、缺席状态和结果显示位置，保存后在座位表面板底部点击“点名”。

- 空座不参与。每人默认权重为 1；权重为 0 或勾选缺席时不参与。
- 开启“本轮不重复”后，抽过的同学本轮不再参与，抽完需手动重置。退出软件后开始新一轮。
- 缺席设置会保留，下次使用前请核对。
- 结果可在本软件、ClassIsland 或两者同时显示。
- 新版设置可启用独立点名悬浮窗；也可设置课间禁用点名。ClassIsland 未运行或课程状态不可用时仍允许点名。
- ClassIsland 通知失败时回退到本软件；“重发此结果”不会重新抽人。

## ClassIsland 联动（可选）

1. 安装并运行 **ClassIsland 2.1.0.1**。
2. 从插件下载页下载 `.cipx` 文件，在 ClassIsland 插件管理中从文件安装，然后重启。
3. 在 ClassIsland 的“SeatSheet 点名”设置页测试提醒，并按需调整显示时长。
4. 在桌面软件的随机点名设置里选择“ClassIsland 显示”或“两者同时”，检查插件连接并保存。

名单与抽取规则在桌面软件中管理；音效、朗读等提醒效果在 ClassIsland 中设置。插件版本与桌面版本不要求相同，当前通信使用协议 v1。

## 日常使用与常见问题

- **打不开面板？** 可以从系统托盘选择“查看座位表”；托盘也能打开设置或退出程序。
- **网络不可用？** 已成功加载过座位表时，可查看最近一次缓存。每次打开面板会自动刷新，也可手动点击“刷新”。
- **动画不流畅？** 展开／还原和设置标签页过渡默认关闭，可在“常规 → 面板显示 → 视觉效果”中分别调整。
- **如何升级？** 退出软件后替换 EXE。配置和缓存保存在 `%LOCALAPPDATA%\SeatSheet.Widget\`，通常无需重新配置；缓存包含座位表内容。
- **下载到的是程序文件夹？** 保留同目录的其他文件。普通构建版本需要 .NET 8 桌面运行时；Release 下载页的单 EXE 自带运行时。

目前按钮和面板位于主屏幕，暂不提供开机启动、暗色主题或全屏应用自动隐藏。问题反馈请使用 [GitHub Issues](https://github.com/AtriDayo/SeatSheet.Widget/issues)，不要公开真实名单或班级网站地址。
