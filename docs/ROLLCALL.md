# 桌面随机点名

设置分为“常规”和“随机点名”两个标签页。点名页从当前加载或缓存的座位表生成参与名单，只包含有姓名或学号的座位；仅有学号时显示“学号 …”。没有姓名和学号的空座不参与。

每人默认权重为 1，可设置 0–100 的整数。权重 2 的抽中概率是权重 1 的两倍；0 或勾选缺席表示不参与。所有修改通过“保存设置”生效，取消和关闭不会写入。名单更新不会写入班级网站，仅在本地读取当前已保存的网站地址；如要更换网站，先在常规页保存新地址。

规则按网站地址与座位表名称隔离，并按学号、姓名识别学生。位置变化仍保留规则；学号或姓名变更会视作新的身份。无法区分的同名同学使用座位补充身份，移动后需要核对权重。保存规则的设置文件留在本机，未加入源码或安装包。

“本轮不重复”开启后，同一班级已抽到的身份不再参与。本轮记录只保存在内存中；重启桌面软件会开启新一轮。抽完不会自动重新开始，需在设置中选择“重置本轮”并保存。缺席设置会一直保留，下一次使用前请核对。

在座位表面板底部点击“点名”开始抽取，与“管理座位”“设置”位于同一组。结果确定后生成一次性的消息 ID 和 60 秒有效期，不依赖 ClassIsland 是否运行。结果窗口可“抽取下一位”，有外部通知时也可“重发此结果”；重发不更改姓名、ID 或有效期。过期结果不能再次通知，但本地结果仍保留。

显示目标可选本软件、ClassIsland、两者同时。ClassIsland 不可用、插件未安装、协议拒绝或回执超时时会回退到本软件展示同一结果。回执超时可能意味着宿主已收到但回执丢失，重发依靠插件的持久去重防止重复提醒。`accepted` 表示已提交宿主提醒系统，不能保证用户开启提醒后一定显示；`duplicate` 表示该 ID 已保留，可能包含之前不确定的提交，不会再次播报。

桌面使用 `ClassIsland.Shared.IPC 2.1.0.1` 的官方管道名和 JSON 请求路由，先验证握手再发送，单次请求总预算约 3 秒。选择外部通知时，每 10 秒握手一次供插件显示客户端活跃状态；本软件模式不做定期握手，也不启动 ClassIsland。仅在打开设置时每秒刷新连接文字，名单列表采用行虚拟化，抽取不使用高频动画。

设置窗口采用 WPF `WindowChrome` 的宽标题区域和内嵌关闭按钮，不增加透明分层窗口。默认宽度为 860，标签文字与名单单元格居中。打开时使用 180 毫秒淡入和轻微位移，关闭时使用 120 毫秒淡出；遵循 Windows 的界面动画开关。点名结果窗口同样使用内嵌关闭按钮。

设置页与结果页共用线条关闭图标和按钮样式，名单勾选框采用同一蓝色主题。面板标题、统计文字和工具栏分列布局，长标题以省略号显示，鼠标悬停可查看完整文字。点名设置里的连接提示跟随当前显示选项；仅本软件显示时无需检查插件，尚未保存的外部显示选项可以手动检查，并标明最近检查时间。

本地点名结果窗口使用透明背景和统一的 18 DIP 圆角边框，避免原生窗口裁切与绘制边缘不一致造成黑边。面板左下角仅显示简短连接信息，正常时为“已连接 · 打开面板时自动刷新”，不显示状态灯或闪烁。座位更新时间与获取时间放在左上角行列信息下方；窄面板可悬停查看完整时间。连接及通知详情可悬停左下角文字查看，通知失败不会改变网站连接状态；实际抽取失败会显示简短的“点名失败 · 查看详情”。

## 检查与试用

```powershell
dotnet run --project tests/SeatSheet.Widget.Checks -c Release
dotnet run --project tests/SeatSheet.ClassIslandPlugin.Checks -c Release
dotnet build src/SeatSheet.Widget -c Release
pwsh -File dev/publish-widget.ps1
```

发布产物仍只有 `artifacts/widget/win-x64/SeatSheet.Widget.exe`。无需更新现有 0.1.5 插件即可试用协议 v1。先保存网站连接并加载座位表，打开随机点名标签页核对名单与规则，保存后回到面板点击点名。选择外部通知时可先点击“检查插件”；其失败不阻止本地点名。

开发用 `--rollcall-qa` 只使用虚构名单，停止真实持久化和后台握手，验证设置取消、保存、过滤与本地结果并输出渲染图片。私有 IPC 检查使用随机命名管道和测试接收端，不向日常 ClassIsland 发送学生信息。
